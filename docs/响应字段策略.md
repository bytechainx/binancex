# 响应字段与批次身份策略清单

`production_decision=NO-GO`。P6 尚未整体验收；本清单用于逐组核对现行约束和待裁决候选，不改变冻结合同、生产准入或源授权。

## 阅读约定

必填字段和批次身份唯一性是两项独立策略。字段有值不代表它能唯一标识一行；字段被选作身份候选也不自动使其成为必填项。对象响应、单对象或数组双形响应、行数组和定长元组分别保留原始结构边界。

| 状态 | 含义 | 允许据此采取的动作 |
| --- | --- | --- |
| `source-guaranteed` | 来源明确声明该约束，且有可回查的源位置；仅对该声明的作用域成立 | 依照已批准合同和实现范围落实，不扩展到相似端点 |
| `local-accepted` | 已经 root 明确采纳的本地入口策略；不声称该策略是源必填保证 | 按已批准范围实现与测试，保留来源和本地决策的区别 |
| `open candidate` | 可用于进一步裁决的字段或身份锚点，当前证据或决策不足 | 仅记录风险与补证方向，不新增拒绝行为，不静默升格 |

冻结树中的 `mandatory=false` **既不等于 required，也不等于已确证 optional**。字段表、示例中出现某字段，或类型层暂用 `Option<T>`，均不能单独证明该字段必填或可省略。表中的候选字段也不构成新的请求或响应合同。

每组分别登记必填字段候选、身份候选、证据 locator 和已实现约束。证据 locator 指向元仓库 `specs/binancex/` 中的冻结树、类型映射或已登记源快照；合成夹具和本地测试只证明实现行为，不作为来源保证。

## 已采纳边界与例外

| 范围 | 已实现或已采纳策略 | 保留边界 |
| --- | --- | --- |
| 普通响应对象 | 具体解析入口要求对象形态，拒绝未知字段；已登记字段的对象拒绝空对象 | 非空对象不等于所有关键字段齐全；命名必填集合须逐组裁决 |
| `SpotAvgPrice` | `local-accepted`：`price`、`closeTime` 缺键报 `Missing`，显式 `null` 或类型错误报 `Invalid` | 不将这两个本地关键字段写成源的普遍必填保证 |
| 保险余额 `assets[]` | 尚无已冻结成员的元素保留为空对象，未知成员失败 | 空对象是未补证结构占位，不能据此判定真实资产内容有效 |
| `referencePrice` | 继续允许缺失或 `null`，保留为缺失，不填零 | 不能因其他价格字段成为关键字段而连带改为必填 |
| 日程 `marketSchedules` | 仅接受已登记六键 `EQUITY`、`COMMODITY`、`KR_EQUITY`、`HK_EQUITY`、`CN_EQUITY`、`FX` | 允许集不要求六键全部出现，也不把源的未来键空间宣称为封闭 |

Kline 已有明确证据的开盘时间身份与 Spot UiKline 的引用推导分别登记。Spot UiKline 的推导尚未采纳；OptionsTrade 的双 ID 也尚未裁决，不能选择其中之一或组合后直接拒绝重复。

## 逐组清单

本节按四族只读研究结果整理 **76 个类型组**：Spot 15、USDM 30、COINM 22、Options 9。多端点共用同一组时保留全部 endpoint_id；USDM 027 的替代映射也保留，health probe 和 excluded 映射不创建类型组行。类型映射本身仍标记 `design_candidate_not_frozen`，登记在这里不改变其状态。

表中 `R?`、`I?` 分别表示 required 与 identity 的 `open candidate`；后面的字段只是候选锚点。`R本地` 是 `local-accepted`；`I源` 是 `source-guaranteed`。`固定12位置` 是冻结元组结构约束，不是另行选定的一组对象 required 字段。`O` 表示 object，`A<O>` 表示对象数组，`O/A<O>` 表示对象或对象数组双形，`A<T12>` 表示十二位置元组数组。

“误拒”列说明擅自采纳候选可能拒绝的合法情形；“漏拒”说明保持现有宽松行为可能遗漏的问题。它们是策略风险分析，不是声称这些输入已从真实源观测到。

## 后续裁决条件

每条候选升格前，分别明确 required 与 identity 的适用端点、响应形态、嵌套路径和请求上下文。源方保证须能回到对应源 locator；本地接收策略须由 root 明确批准并记录误拒影响。仅有请求参数 required、示例出现、字段名像 ID 或样本频率，均不足以形成响应字段保证。

已批准规则再由实现和负例固定：最小可接受对象、逐项删键、null、双形、嵌套位置和适用的重复身份。测试固定本地政策及实现，不产生源证据。冻结合同变化、证据定位失效或类型组集合变化时，先报告差异并重新裁决，不能借维护文档直接扩展 parser 拒绝行为。

本清单保留 **12 组 `I源`**（Spot 1、USDM 5、COINM 5、Options 1）及 **1 组 `R本地`**（SpotAvgPrice）。其他候选未获本清单采纳，P6 未整体验收状态与 `production_decision=NO-GO` 保持不变。
